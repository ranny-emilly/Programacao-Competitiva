# Biblioteca de Programação Competitiva

Material de estudo e consulta em C++17, organizado a partir dos templates e das soluções deste repositório. O índice separa explicações para aprender de implementações locais para consultar.

## Aprender

- [C++ e STL](BIBLIOTECA/cpp-stl.md) — básico: template usado, tipos, contêineres, ordenação e limites da STL.
- [Técnicas em vetores](BIBLIOTECA/tecnicas.md) — básico/intermediário: busca binária, prefix sum, janela e Kadane.
- [Grafos](BIBLIOTECA/grafos.md) — básico/intermediário: representação, DFS, BFS, ciclos, caminhos, bipartição e Dijkstra.
- [Matemática](BIBLIOTECA/matematica.md) — básico/intermediário: MDC/MMC, primos e operações modulares.
- [Estruturas de dados](BIBLIOTECA/estruturas.md) — intermediário: DSU, Fenwick e Segment Tree.
- [DP, greedy e estratégia](BIBLIOTECA/dp-greedy-estrategia.md) — básico/intermediário: estados, LIS, prova gulosa, debug e complexidade.
